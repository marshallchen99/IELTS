## 维持期和备考期的区别

| | 备考期 | 维持期 |
|---|---|---|
| 每次指出几条 | 全部记账 | **最多 3 条** |
| 排行榜 / 累计次数 | 每场重排 | **不再统计** |
| 收尾包 / 状态块 | 每场自动生成 | **不出，明确要才出** |
| 计划与进度 | 六天冲刺 | **不设计划，来了就练，说停就停** |
| 重点 | Part 3 刷分 | **Part 2（唯一没练透的）+ 听力** |

## 备考期留下来、现在仍然成立的东西

- **骨架**：立场 ≤12 词 → One big reason is that… → For example（具体的人 + 时间点 + 看得见的结果）→ So yeah 给答案
- **例子要用普通人都懂的东西**，技术圈的词一律换掉 —— 这条被真实考官当场验证过
- **本国的东西主动挂一句解释**（Weibo — that's the Chinese equivalent of Facebook），这个动作加分
- **说错往前走，绝不回句首重说**
- **小词优先，听得懂比用词精准值钱**
