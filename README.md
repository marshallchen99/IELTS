# Claude Project 设置指南 · 雅思口语陪练

一次性设置约 5 分钟，之后每天只有一个动作。

> **本文件放哪：哪儿都不放，不要传进 Project。**
> 自定义指令和知识库都别放 —— 第五节的「冷启动块」是规则的浓缩版，传进知识库万一被检索到，Claude 可能照着缩水版执行，正好踩中"同一套规则存两份、各自漂移"的坑。
>
> 设置步骤看完就用不到了。**唯一要留的是第五节的冷启动块 —— 单独复制到手机备忘录**，Project 出问题时能应急。

---

## 一、机制：为什么东西要分两处放

Project 有两个槽，行为**完全不同**：

| | 自定义指令（项目说明） | 知识库（上传的文件） |
|---|---|---|
| 何时进入上下文 | **每次对话强制注入** | **按需检索**，不保证被读到 |
| 谁能改 | 你在设置里编辑文本框 | 你替换文件；**Claude 改不了** |
| 适合放 | 规则、当前靶子 —— 绝不能漏的东西 | 长文档 —— 查得到就行 |

**两个推论，整套流程都是从这来的：**

1. **最关键、最易变的信息（当前两个靶子）必须放自定义指令**，不能放文件里赌它被检索到。
2. **Claude 无法写入知识库文件** —— 它只能把新版内容输出给你，由你替换。所以别指望"每答一题就自动落盘"，那在 Project 里做不到。

---

## 二、设置（做一次）

**1. 建 Project**
claude.ai → Projects → 新建，名字随便（比如 `IELTS`）。

**2. 粘自定义指令 ← 最重要的一步**
打开 `PROJECT_INSTRUCTIONS.md`，**整份复制**，粘进 Project 的自定义指令框，保存。
一个字都不用改 —— 它是照着"直接粘贴"写的。

**3. 上传知识库（3 个文件）**

| 文件 | 作用 | 更新频率 |
|---|---|---|
| `IELTS_Error_Log.md` | 主文件，按错误类型排序的滚动日志 | 每 2–3 天 |
| `IELTS_Exam_Day_Cheatsheet.md` | 考场速查卡 | 基本不动 |
| `IELTS_6Day_Plan.md` | 六天计划 + 实际执行对照 | 基本不动 |

> **完整对话存档（5525 行）不要上传。** 它有 220KB，会挤占检索预算，而平时用不到。留在手机/网盘里，需要核对历史时再说。

**4. 验证设置成功**
在 Project 里开一个新对话，只说四个字：**开始 Day 3**。

Claude 应该**直接报出**：今天 Day 3、话题 Education、两个靶子（主语跟到底 / -s 隔从句挂住），然后出题。
**如果它反问"我们上次练到哪了"，说明指令没生效** —— 回去检查第 2 步是不是粘在了正确的框里。

## 三、每天怎么用

**上班地铁 / 下班地铁（打字）**
在 Project 里开新对话 → 说"Day N 早通勤"或"Day N 晚通勤" → 直接开始。
👉 这两小时 Claude **用中文讲评、可以用表格**，方便你在手机上扫。你打的答案照样是英文，不影响。

**到家一小时（语音）**
在 Project 里开新对话 → 开语音模式 → **说"Day N 出声场，开始"** ← 这句话是切换开关，别省。
👉 从这句起 Claude 切成**纯英文、零 markdown 符号**。中途你想用中文问就直接用中文，它回一条中文然后自动切回英文。

> **语言默认是中文。** 只有"出声场 / 语音 / 到家了"这类话才会切英文。
> 万一它在地铁上还是回英文，一句"**切回中文**"即可。

> ⚠️ 先确认你的手机 App **能在 Project 对话里开语音**。如果开不了，就在普通对话里练，开场先粘一次「冷启动块」（见下方第五节）。

## 四、每天唯一的义务：粘贴一次

**你不用开口要。** 指令里写死了：出声场最后一题的反馈一讲完，Claude **自动**输出一个代码块 —— 那是「📍 当前状态」区块的完整新版。

你要做的只有一件事：

> **复制那个代码块 → 打开项目设置 → 替换掉自定义指令末尾的「📍 当前状态」整段 → 保存**

**30 秒，一天一次。** 它同时带着「🕓 待入库」小节，本场每道题的错误都在里面，所以**粘一次就什么都不会丢**。

### 触发条件（写在指令里，多重保险）

- 最后一题反馈讲完 → 立刻给，不等你说话
- 你说了任何收工信号：困了 / 累了 / 结束 / 睡了 / 明天见 / good night…
- 你开始聊别的、或连续两轮没在答题
- 原则是"**拿不准就给**" —— 漏一次就整场数据没了，多给一次只是几行字

**万一它还是没给**（模型偶尔会漏），一句话补救：

> 出收尾包

### 每 2–3 天（到电脑前时）再做一次

> 把错误日志出完整新版，并清空待入库

它输出完整 markdown → 你存成 `IELTS_Error_Log.md` → 删掉知识库旧文件 → 传新的。

> **为什么不每天换文件？** 55KB 全文每天重出既费时又容易漂移；而且你晚上在手机上编辑文本框容易，替换文件难。
> **靶子和当日错误天天粘进指令，日志文件几天一换** —— 两边都不断，代价最小。

## 五、冷启动块（应急用，存手机备忘录）

万一 Project 用不了、或者你在别的地方临时要练，把这段粘进任何一个新对话，最关键的东西就都在了：

```
你是我的雅思口语陪练。规则：
1. 语言按场次分两档，不按单条消息判断。默认是"通勤打字场"：你用中文讲评，可以用markdown表格——我在地铁上看屏幕，中文才扫得快。注意我打的答案是英文的，那不是切换信号。只有我说"出声场/语音/到家了"，你才切成纯英文、且不许出现任何markdown符号（星号井号编号加粗一律禁止），只用纯口语句子；那一小时里我用中文插话你可以中文回一条，然后立刻切回英文。我说结束就切回中文。
2. 我的三小时：上班地铁1h打字（不能出声，只能对嘴型）+ 下班地铁1h打字（同上）+ 到家1h语音出声。地铁场不要安排需要放音频或录音的东西。
3. 当考官：每题35-40秒超时打断，要求3秒内开口，说错不许回头重说，每场只盯1-2个靶子其余静默记账。示范答案按6.5档，只用我说过的词。
4. 我当前两个靶子：① 一个主语跟到底，绝不中途跳 I/you/them ② 三单-s隔从句也要挂住，但情态动词后不加（would mean 不是 would means）。
5. 不要凭语音转写反向纠正我——转写会凭空造错。我说我说对了就信我。
6. 我写作7分口语6分，瓶颈是提取速度不是知识，语法填空题别给我做。
7. 这一场结束时（最后一题讲完，或我说累了/结束/晚安），你不用等我要，自动输出一个代码块：本场每题的错误一行一条（我说的→应该说）+ 更新后的两个靶子。代码块内部用中文markdown，你自己的话仍然照第1条。
```
