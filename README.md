## 🧠 怎么让它真的不被忘掉

Claude 本身**没有可以主动写入的永久记忆层**。会话一结束，细节就不在了。
所以"永久记忆"不能靠模型记，只能靠**文件 + 自动加载机制**。这个仓库就是那个机制：

### 1. Claude Code（网页 / CLI / 桌面端）—— 全自动

根目录的 `CLAUDE.md` 会在**每次新会话开始时自动读进上下文**，不需要你说任何话。
所以只要在这个仓库里开会话，三小时分配、语言规则、当前靶子就已经在了。

**你要做的：什么都不用做。** 直接说"开始 Day 3"就行。

### 2. claude.ai / 手机 App（你做语音对练的地方）—— 一次性设置

语音模式不读 GitHub 仓库，所以要手动挂一次：

1. 在 claude.ai 建一个 Project，名字随便（比如 `IELTS`）
2. 把 **`CLAUDE.md` 全文**粘贴进 Project 的**自定义指令**
3. 把 `IELTS_Error_Log.md` 上传到该 Project 的知识库
4. 以后所有练习都在这个 Project 里开新对话

`CLAUDE.md` 是照着"能直接粘贴"写的，不用改一个字。

### 3. 每天收尾时（这一步不能省）

一场练完，让 Claude 更新 `IELTS_Error_Log.md` 和 `CLAUDE.md` 第 6 节「当前状态」，然后 commit + push。
**文件是那个永远不会忘的东西，Claude 只是读文件的人。**

> 如果 Claude 哪天又忘了规矩（已经发生过三次），直接说一句："**读 CLAUDE.md**"。

## 🔑 三条最值钱的发现

1. **骨架法有效。** Day 2 Q8「退休年龄」他说"完全没思路"，给了三句骨架后产出了当晚结构最干净的答案。
   **想不出观点不是能力问题，是缺容器。**
2. **写对 ≠ 说得出来。** 写作 7 分、口语 6 分，语法填空基本全对，说的时候同样的点全错。
   **下结论只看出声场的数据。**
3. **同一个毛病，写四行骨架时不犯，放开说时会犯。** 变量是**输出长度和自由度**，不是打字还是出声。

## 📝 数据可信度说明

- 归档 transcript 的时间戳是 **UTC**，本仓库所有日期已换算成**本地时间 UTC+8**（换算依据见错误日志的时间线一节）
- 语音转写**会凭空造错**（已确认两例：`addictive` → `active`、`prematurely` → `maturely`）。
  凡是标注「存疑」的条目，以本人记忆为准
